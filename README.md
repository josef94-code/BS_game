# BS_game – Lernspiele für die Berufsschule

Sammlung von Lernspielen. Jedes Spiel liegt in einem eigenen Ordner und hat dort seine eigene README mit Anleitung, Lernfeldbezug und Lösungen.

| Spiel | Zielgruppe | Ordner |
|---|---|---|
| **NACHTSCHICHT** – Survival-Rätselspiel in einer verrotteten Werkshalle | Mechatroniker/-in, 1. Ausbildungsjahr (LF 1–4) | [`nachtschicht/`](nachtschicht/) |

`index.html` im Hauptordner ist eine kleine Startseite mit Links zu allen Spielen.

## Neues Spiel anlegen

1. Neuen Ordner anlegen, z. B. `mein-spiel/`, mit eigener `index.html`, `README.md` usw.
2. Das Spiel in die Tabelle oben und in die Startseite `index.html` eintragen.
